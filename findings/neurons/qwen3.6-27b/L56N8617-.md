# Shallow Copy vs Deep Copy in Python

## The Core Difference

The difference revolves around **how nested objects are handled**:

- **Shallow copy** creates a new container, but the *contents* are still references to the original nested objects.
- **Deep copy** creates a new container **and** recursively copies all nested objects, so the copy is completely independent.

## Example

```python
import copy

original = [1, 2, [3, 4]]  # List with a nested list

# ---------- Shallow Copy ----------
shallow = copy.copy(original)       # or: shallow = original[:]

shallow[2][0] = 99  # Modify the nested list through the shallow copy

print(original)  # [1, 2, [99, 4]]  ← Original is also changed!
print(shallow)   # [1, 2, [99, 4]]

# ---------- Deep Copy ----------
deep = copy.deepcopy(original)       # Reset original first for clarity
original = [1, 2, [3, 4]]

deep[2][0] = 99  # Modify the nested list through the deep copy

print(original)  # [1, 2, [3, 4]]    ← Original is untouched!
```
