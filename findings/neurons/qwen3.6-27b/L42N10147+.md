```
In Python, a **shallow copy** creates a new collection with the same references, while a **deep copy** recursively creates entirely new objects.

The main difference lies in how they handle nested objects:
*   **Shallow Copy**: Creates a new container but populates it with references to the same objects found in the original.
*   **Deep Copy**: Recursively creates new objects for all nested levels.

Here's a brief example:

```python
# Import the copy module
import copy

# Original list
original = [[1, 2, 3], [4, 5, 6]]

# Shallow Copy: 
# Creates a new list but references the same inner lists.
shallow_copy = copy.copy(original)  # See also: copy.deepcopy(original)
print(original == shallow_copy)     # True, same values
print(original is shallow_copy)     # False, different containers
print(original[0] is shallow_copy[0])  # True, same inner objects!

# Deep Copy: Creates entirely new copies of all nested objects.
deep_copy = copy.deepcopy(original)
print(original == deep_copy)        
```
