How to read this

Chance of turning weird

Agastya cut each weird reply at about ten places. At each cut he regenerated the rest of the reply 8 to 16 times from the same prefix and had Gemma 4 31B judge every continuation. Dotted underlines mark the measured cuts; between cuts the last measured value carries forward. The fork is the token where the chance jumps the most, found by bisection.

Removing neurons

Each reply was run once normally and once with a neuron set zeroed at the MLP output, feeding the same tokens. A set's support for a token is how much less likely the token becomes without the set, in nats; 2.3 nats is a tenfold drop. Own sets are each behavior's top 100 neurons by attribution at its forks. The shared set is 100 neurons from layers 24 to 47 that lower all eight behaviors. Each set has a random control drawn from the same layers with matched activation size.

In-sample caution

Every forked reply here comes from Agastya's discovery prompts, and the own sets were picked by attribution at these same forks, so strong support at a fork token is expected by construction. The out-of-sample evidence is his held-out rate results in the bars above. This view adds where else in a reply a set matters, and how normal replies to the same prompt compare.

Neuron activations

Activations are read at the position that produced the token, so they show the state the model was in when it chose it. Oracle-lens readouts will be added at each token once that run is validated.
