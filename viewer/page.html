How to read this

Chance of turning weird. Agastya cut each weird reply at about ten places. At each cut he regenerated the rest of the reply 8 to 16 times from the same prefix and had Gemma 4 31B judge every continuation. Dotted underlines mark the measured cuts; between cuts the viewer carries the last measured value forward. The fork is the token after which the chance jumps the most, found by bisection.

Removing neurons. We ran each reply once normally and once with a neuron set zeroed at the MLP output (down_proj input), feeding the same tokens. The set's support for a token is how much less likely the token becomes without the set, in nats. Each set has a random control: neurons drawn from the same layers with matched activation size. Own sets are each behavior's top 100 neurons by attribution at its forks; the shared set is 100 neurons from layers 24 to 47 that lower all eight behaviors.

In-sample caution. Every forked reply here comes from Agastya's discovery prompts, and the own sets were selected by attribution at these same forks. Strong support at a fork token is therefore expected by construction. Out-of-sample evidence is his held-out rate results (the bars at the top). What this view adds is where else in a reply the set matters, and how normal replies to the same prompt compare.

Neuron activations are read at the position that produced the token, so they are the state the model was in when it chose it. Oracle-lens readouts will be added at each token once that run is validated.
